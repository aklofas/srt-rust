# tstrans-srt-sys

Raw FFI bindings to Haivision libsrt 1.5.x, generated by bindgen. It ships
no safe wrapper — see `tst-srt` for the safe API tstrans applications use.

**Bundled source.** This crate packages the pinned libsrt v1.5.6 tree and
builds it when no suitable system libsrt >= 1.5.0 is found via pkg-config.
Set `SRT_FORCE_VENDORED=1` to force the vendored build even when a system
libsrt is present.

**Build prerequisites:** a C/C++ toolchain and CMake (for libsrt), plus
libclang (for bindgen) — see the `bindgen` crate's requirements for
platform-specific libclang setup.

**Stability: Internal.** This crate is an implementation detail of the
tstrans workspace. You should not depend on it directly.
